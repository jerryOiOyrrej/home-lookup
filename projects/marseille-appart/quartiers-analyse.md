# Analyse des quartiers – Marseille

## Critères de filtrage
- < 20 min vélo de Saint-Charles ET du Vieux-Port
- Vivant + commerces mais calme le soir
- Pas de pente raide (vélo friendly)
- Cachet / charme

## 🟢 Quartiers prioritaires

### 1. Cinq Avenues / Longchamp (4e)
- **Distance** : 5-10 min vélo de Saint-Charles, 10-15 min du port
- **Ambiance** : Résidentiel bourgeois, calme le soir, commerces sur les avenues
- **Terrain** : Relativement plat
- **Immobilier** : Beaux immeubles haussmanniens, hauteur sous plafond, parquet
- **Budget** : Accessible dans la fourchette haute
- **⚡ Match** : Très bon — calme, cachet, proximité gare

### 2. Vauban / Castellane (6e)
- **Distance** : 10 min vélo de Saint-Charles, 10 min du port
- **Ambiance** : Quartier chic, commerçant (rue Paradis, rue de Rome)
- **Terrain** : Plat à modéré
- **Immobilier** : Bel ancien, grandes surfaces disponibles
- **Budget** : Correspond bien (quartier prisé)
- **⚡ Match** : Excellent — central, vivant, beau patrimoine

### 3. Notre-Dame-du-Mont / Cours Julien (6e)
- **Distance** : 10 min vélo de tout
- **Ambiance** : Très vivant, bars/restos/culture, bohème
- **Terrain** : Plat
- **Immobilier** : Ancien avec cachet, lofts, ateliers rénovés
- **Budget** : Plus abordable, gros potentiel rénovation
- **⚠️ Attention** : Peut être bruyant le soir (bars) — choisir une rue en retrait

### 4. Endoume / Bompard (7e)
- **Distance** : 15-20 min vélo du port, 20 min de Saint-Charles
- **Ambiance** : Village dans la ville, très calme le soir, vue mer possible
- **Terrain** : ⚠️ Vallonné — certaines rues en pente
- **Immobilier** : Maisons de ville, petits immeubles avec charme
- **Budget** : Haut de fourchette pour vue mer
- **⚡ Match** : Bon si tolérance pente — gros coup de cœur possible

### 5. Saint-Victor / Le Pharo (7e)
- **Distance** : 5-10 min vélo du port, 15 min de Saint-Charles
- **Ambiance** : Quartier historique, calme, vue mer/fort
- **Terrain** : Modéré
- **Immobilier** : Ancien rénové, belles pierres
- **Budget** : Dans la fourchette
- **⚡ Match** : Très bon — charme + proximité port

### 6. La Plaine / Le Camas (5e)
- **Distance** : 10 min vélo de tout
- **Ambiance** : Marché de la Plaine, populaire et vivant
- **Terrain** : Plat
- **Immobilier** : En pleine gentrification, beaux apparts rénovés
- **Budget** : Bon rapport qualité/prix
- **⚠️ Attention** : Bruyant les jours de marché

### 7. Périer / Rond-Point du Prado (8e)
- **Distance** : 15 min vélo du port, 20 min de Saint-Charles
- **Ambiance** : Bourgeois, calme, proche plages du Prado
- **Terrain** : Plat (grands boulevards)
- **Immobilier** : Grands apparts, résidences standing
- **Budget** : Correspond bien
- **⚡ Match** : Bon — calme, spacieux, proche plage

## 🔴 Quartiers écartés
- **1er (Belsunce/Noailles)** : trop bruyant, parties communes souvent dégradées
- **2e (Joliette/Panier)** : en mutation, encore instable, pentes
- **3e** : quartiers nord, ne correspond pas
- **Quartiers sud lointains (Calanques, Mazargues)** : trop loin à vélo

## 🎯 Top 3 recommandé
1. **Vauban / Castellane (6e)** — le sweet spot
2. **Cinq Avenues / Longchamp (4e)** — le calme avec le cachet
3. **Saint-Victor (7e)** — le charme près du port
